## 公开文件完整性校验

仓库根目录提供 `MANIFEST.sha256`，记录公开文件的 SHA-256。下载者可在仓库根目录使用支持该格式的校验工具检查文件是否发生变化，例如：

```bash
sha256sum -c MANIFEST.sha256
```

校验时应注意：

- 文件新增、删除或合法修改后，需要重新生成清单，否则校验失败是预期行为；
- `MANIFEST.sha256` 本身不包含在自身清单中；
- 哈希清单只能证明“文件是否与清单一致”，不能单独证明清单由谁发布。

## 数字签名的适用边界

`sign.sh` 是作者发布前生成清单并创建 GPG 分离签名的辅助脚本。只有在发布包实际附带 `MANIFEST.sha256.sig`、且验证者已取得并信任作者公钥时，才能进一步验证签名：

```bash
gpg --verify MANIFEST.sha256.sig MANIFEST.sha256
```

**当前公开文件清单中未包含 `MANIFEST.sha256.sig`，因此本仓库不把“签名文件可验证”写成当前已具备的能力。** 如果后续发布版本附带该文件，以上命令才适用。

GitHub 提交的 **Verified** 状态同样应以实际提交页面和平台验证结果为准，不能仅通过文档声明或徽章预先保证。
